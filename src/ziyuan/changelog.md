# 更新日志

## v1.2.3 (2026-05-05)

### 功能支持
- 新增 DeepL 翻译服务，支持输入 DeepL API Key 后识别 Free / Pro 身份
- 保留 Google 翻译为默认服务
- AI 通用接口继续支持智谱、OpenAI、DeepSeek、通义千问、字节豆包、Google Gemini 和自定义配置

### 优化改进
- 引入 QtAwesome 图标，替换主界面标题栏、工具按钮和信息按钮中的旧 SVG 图标
- 优化系统字体策略，禁用并移除 PingFang 字体，改用系统黑体
- 移除内置字体文件和打包引用，发行包仅使用系统字体
- 统一主题样式和迷你窗口字体声明为 SimHei，避免控件间字体回退不一致
- 设置页 DeepL 配置仅保留 API Key 输入与身份验证入口
- 设置页输入框右键菜单改为中文
- Google 服务重试时先显示“正在连接”，只有真实连通后才显示“已连接”
- Windows 在线更新改为全量静默替换，不再启动安装器

### 问题修复
- 修复开机自启在开发环境和安装环境下目标路径、工作目录、图标路径不一致的问题
- 修复开机自启设置保存失败时仍写入配置的问题
- 修复更新下载缓存残留、下载路径和安装提示的若干边界问题
- 修复静默更新失败回滚、卸载文件保留、跨盘安装和异常版本号解析问题
- 修复配置文件异常损坏后无法自动恢复的问题，配置保存改为原子写入
- 修复异常退出后单实例锁残留导致无法再次启动的问题
- 修复 Google 翻译连接未校验证书的问题
- 修复窗口事件过滤器被重复定义导致的缩放和激活事件处理不稳定问题
- 修复 Mini 模式托盘入口、快捷键启停和翻译错误状态显示的若干一致性问题
- 修复主题菜单、托盘菜单、更新弹窗等在不同主题下的样式不一致问题

### 其他变更
- 移除 Achord 自研翻译引擎
- 版本号更新为 1.2.3
