## 使用方法

### 快捷键

- `Ctrl+Shift+C`：复制并翻译文本
- `Ctrl+Shift+M`：切换迷你模式/标准模式
- `Ctrl+Shift+H`：显示/隐藏迷你窗口

### 迷你模式使用技巧

1. 启用迷你模式后，主窗口会隐藏
2. 使用快捷键 `Ctrl+Shift+C` 可直接翻译剪贴板内容
3. 迷你窗口会自动调整大小以显示完整翻译结果
4. 点击迷你窗口右上角的方框图标可切换回主窗口

## 使用说明

1. 启动程序
2. 选择翻译服务
3. 输入要翻译的文本或使用快捷键
4. 查看翻译结果

### 快捷键
- `Ctrl+C,C`: 快速呼出翻译窗口
- `Ctrl+Alt+T`: 备用快捷键
- `Alt+M`: 切换 Mini 模式
- `Alt+H`: 显示/隐藏 Mini 窗口

### 系统托盘
- 右键托盘图标可以：
  - 显示/隐藏主窗口
  - 检查更新
  - 查看软件信息
  - 退出程序

### 自动更新
- 程序启动时自动检查更新
- 可以通过托盘菜单手动检查更新
- 支持强制更新和可选更新两种模式

### 翻译服务配置
- Google: 无需配置，但需要确保网络能访问 Google 服务
- AI（通用接口 / OpenAI 兼容）: 需要在设置页填写
  - 厂家（Vendor）
  - 模型 URL（Base URL）
  - 模型名（Model）
  - API Key
  - 支持按厂家保存配置，切换厂家不会互相覆盖

常见 Base URL 参考：
- 智谱: https://open.bigmodel.cn/api/paas/v4
- OpenAI: https://api.openai.com/v1
- DeepSeek: https://api.deepseek.com
- 通义千问(Qwen): https://dashscope.aliyuncs.com/compatible-mode/v1
- 字节豆包: https://ark.cn-beijing.volces.com/api/v3
- Google Gemini: https://generativelanguage.googleapis.com/v1beta/openai

## 开发说明

### 环境要求
- Python 3.10+
- PyQt5
- 其他依赖见 requirements.txt

### 安装依赖
```bash
# 使用项目自带虚拟环境（推荐）
# Windows:
.venv311\Scripts\activate
# Linux/macOS:
source .venv311/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### 运行开发版本
```bash
# 推荐：在【项目根目录】运行（最稳，不依赖当前工作目录）
python -m src.main

# 开发调试模式（不隐藏控制台，便于查看日志/报错）
python -m src.main --debug

# 如果你当前就在【src 目录】下，也可以这样运行：
python main.py

# src 目录下的调试模式：
python main.py --debug
```

### 打包发布

#### 1. 使用 PyInstaller 打包程序
```bash
# Windows 系统下运行
.\build.bat

# 或手动执行以下命令
pyinstaller --clean --noconfirm build.spec
```

build.spec 文件已配置：
- 将所有依赖打包到单个 exe 文件
- 包含所有必要的资源文件
- 设置程序图标
- 关闭控制台窗口

#### 2. 使用 Inno Setup 创建安装程序
1. 安装 [Inno Setup](https://jrsoftware.org/isinfo.php)
2. 使用 Inno Setup Compiler 打开 `setup.iss`
3. 点击 "Build" -> "Compile" 或按 Ctrl+F9
4. 生成的安装程序在 `output` 目录中

setup.iss 文件已配置：
- 中文界面
- 程序图标
- 开始菜单快捷方式
- 桌面快捷方式（可选）
- 卸载程序

## 注意事项

1. 全局快捷键功能需要管理员权限
2. 部分翻译服务需要配置 API 密钥
3. Google 翻译需要确保网络访问

5. 打包时确保虚拟环境中安装了所有依赖
6. 打包路径不要包含中文和空格
